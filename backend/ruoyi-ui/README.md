# 星绾同行管理后台前端

> Vue 2 + Element UI 的星绾同行管理后台前端，面向健康记录、目标打卡和圈子运营管理。

## 当前管理域

| 菜单 | 说明 |
|------|------|
| 数据概览 | 用户、圈子、五类记录、今日动态、待审核内容、待处理反馈等运营指标 |
| 用户中心 | 用户信息与用户画像抽屉 |
| 圈子中心 | 圈子、分类、成员、目标、排行榜等圈子业务 |
| 押金中心 | 押金记录与退款处理 |
| 记录管理 | 体重 / 饮食 / 运动 / 饮水 / 习惯打卡统一台账 |
| 社区中心 | 动态审核、评论管理、成就等社区内容 |
| 运营支持 | 系统通知、用户反馈处理 |

## 开发

```bash
cd backend/ruoyi-ui
npm install
npm run dev
```

默认开发服务：

```text
http://127.0.0.1:1024/
```

## 发布构建

```bash
cd backend/ruoyi-ui
npm run build:prod
```

构建产物输出到：

```text
backend/ruoyi-ui/dist
```

## 当前巡检重点

- 数据概览运营卡片能跳转到动态审核、评论管理、系统通知和用户反馈
- 记录管理五个 Tab 都能加载，图片预览和来源动态反查可用
- 动态审核支持精选 / 取消精选、状态切换和图片预览
- 评论管理支持状态切换、图片预览和跳转动态
- 用户反馈支持筛选、查看截图、填写处理回复，并触发小程序系统通知

详细巡检记录见 [后台体验审查](../../docs/ADMIN_UX_REVIEW.md)。
