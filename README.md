# Xingwan Companion

A cross-platform health habit application covering weight records, meals, activity, habits, trends, community interactions, and an administration backend.

## Structure

- `prototype/`: interaction prototypes
- `backend/`: Spring Boot/RuoYi backend and administration frontend
- `mobile/`: uni-app Vue 3 + TypeScript client

## Local development

Use the example configuration files and provide database, Redis, and optional WeChat credentials through local environment variables. Run the backend with Maven and the mobile client with the uni-app toolchain.

This public preparation copy excludes production credentials, certificates, database backups, user records, uploaded media, build output, and deployment notes.
